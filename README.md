# Hangman Word Guessing Game

## task Overview
Hangman is a simple command-line word guessing game developed using Python 3. The player tries to guess a hidden word by entering one letter at a time.

The game provides a limited number of incorrect attempts. The player wins by guessing all letters correctly before running out of attempts.

## Features
   Random word selection.
   Six incorrect attempts allowed.
   Displays correctly guessed letters.
   Shows remaining attempts.
   Prevents repeated letter guesses.
   Displays win or lose messages.
   Allows the player to play again.

## Technologies Used
- Python 3
- Random Module

## How to Run the Project

1. Install Python 3 on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python hangman.py
```

## How to Play
1. Run the Python program.
2. The game selects a random hidden word.
3. Enter one letter at a time.
4. Guess the word before using all six incorrect attempts.
5. Choose whether to play again after the game ends.
