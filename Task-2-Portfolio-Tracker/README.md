# Task 2 – Investment Portfolio Tracker

## Description
A Python-based investment portfolio tracking utility that validates S&P 500 stock symbols, fetches the latest available stock prices, and calculates portfolio performance.

## Features
- Stock ticker validation using S&P 500 dataset.
- Fetches stock prices using yfinance.
- Calculates total invested capital and current market value.
- Calculates profit/loss and percentage gain or loss.
- Exports portfolio summary to a CSV file.

## Technologies
- Python 3
- CSV Module
- yfinance
- S&P 500 Dataset

## Files
- `portfolio.py` – Main Python program.
- `constituents.csv` – S&P 500 company dataset.
- `portfolio_summary.csv` – Generated portfolio report.
