# Automated File Organizer and Cleanup Utility

## task Description
A Python-based desktop utility that automatically organizes files into categorized folders and cleans up temporary files.

## Features
- Organizes Documents, Images, Videos, Archives, and Code files.
- Moves unknown file types into an Others folder.
- Handles naming collisions.
- Deletes temporary files after user confirmation.
- Removes empty folders.
- Maintains an activity log.
- Displays an execution summary.

## Technologies Used
- Python 3
- os
- shutil
- pathlib
- logging

## How to Run
1. Open the project folder in VS Code.
2. Run `python organizer.py`.
3. Enter the directory path.
4. Select an operation from the menu.
